# Demonstration script

A path of under four minutes that a judge or presenter can follow signed out, with the fictional demo data (`make seed-demo`) or the browser-test mock. It uses the six-project pilot narrative: the six seeded records are read one after another for what each source-backed record does and does not say. **No line below states a fact about a real project**: read what each record itself shows, and do not add claims. Three of the six records have no verified fact because their sources block automated access; that is part of the story, and the page says so.

Times are targets. Use the English routes; repeat one step in another language if there is time.

| Time | Step | What to point at |
| --- | --- | --- |
| 0:00 | Open `/en`. | One sentence of purpose, the search box, "Report a concern privately", and the language links. Not an emergency service. |
| 0:20 | Browse the six records (the directory). Filter by locality (AMAC, then Bwari). | The same records for each council; status and "last checked" on every card; a record with no verified fact says so. |
| 0:50 | Open a record with verified facts; follow a citation. | Each statement has its own label in words; the source passage is quoted exactly; "Back to the statement". |
| 1:15 | Ask the record a question, then ask one it cannot answer. | A cited answer labelled as written by AI from approved sources; the second answer is the refusal, not a guess. |
| 1:40 | Start Source Scout on the record. | Every result reads "discovered — not yet reviewed"; analysis is "an explanation, not a source" with no score. |
| 2:00 | Report a concern (fictional): keep it anonymous, add a photo. | The safety notice comes first; the code is shown once and never again; a reload cannot bring it back. |
| 2:30 | Look the code up on `/en/track`. | A public-safe status only; nothing private. |
| 2:45 | Sign in as the demo reviewer (`REVIEWER_BOOTSTRAP_*`, local only). Open the queue, then the report. | Minimal-data queue; contact is hidden until asked; evidence downloads only on request. |
| 3:10 | Change the status. Then draft a public update from approved citations and preview it. | A status change says "nothing was published"; the preview is exactly the public timeline entry. Publish it and open the record. |
| 3:40 | Turn the network off on a record you opened; reload. Turn on low-data mode. | "A saved copy from ... may be out of date"; no private page is available offline. |

Fallbacks: if a live provider is asked for, the demo uses recorded replays and says so ("Showing a fictional replay for the demo"). Nothing in this path needs an API key. Do not enter a real name, contact, or event.

Known limits to mention when asked: no hosted deployment yet; Hausa, Igbo, and Yoruba copy is mostly pending fluent review; no screen-reader smoke run yet; the visual finish has not had an independent review.
